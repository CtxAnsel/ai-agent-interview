# AI Agent 核心基础面试题

## 1. 什么是 AI Agent？与普通 LLM 应用有什么区别？

**参考答案：** AI Agent 是以模型为决策核心、能够根据目标与环境反馈选择行动的系统。普通 LLM 应用通常完成一次输入到输出；Agent 可以在循环中观察状态、调用工具、检查结果并调整下一步。Agent 并不一定需要自主规划，实际自主程度由系统设计决定。

**追问：** 什么时候不应该使用 Agent？任务流程固定、可确定性要求高时，优先采用工作流或普通函数调用，降低成本和不可控性。

## 2. ReAct 是什么？

**参考答案：** ReAct 将推理与行动交替进行：根据当前信息选择动作，执行工具，再利用工具结果继续决策。实际实现通常是结构化工具调用循环，不要求暴露模型的私有推理内容。

**工程关注：** 最大迭代次数、超时、工具参数校验、重复调用检测和失败恢复。

## 3. Tool Calling 的执行流程是什么？

**参考答案：** 开发者向模型声明工具名称、用途和参数 schema；模型返回结构化调用请求；应用侧校验权限和参数、执行工具，并将结果返回模型以生成下一步动作或答案。模型本身通常不直接执行外部代码。

**追问：** 如何防止危险工具调用？使用最小权限、用户确认、参数白名单、审计日志和沙箱隔离。

## 4. Agent 的短期记忆与长期记忆有什么区别？

**参考答案：** 短期记忆主要是当前任务的上下文、消息与状态；长期记忆是跨会话保留的事实、偏好或经验，可存储在数据库或检索系统。长期记忆需要考虑过期、纠错、隐私和访问控制。

## 5. 如何避免 Agent 陷入无限循环？

**参考答案：** 设置步骤数、时间和预算上限；检测重复工具调用；定义明确的终止条件；对于连续失败进行降级或人工接管。对每个工具设置超时、重试上限和幂等策略。

## 6. Agent 与 Workflow 有什么区别？

**参考答案：** Workflow 的流程由开发者显式定义，Agent 的下一步选择更多由模型根据当前状态决定。生产系统通常采用混合架构：确定性流程控制关键节点，模型处理开放性决策。

## 7. 如何评估 Agent 的质量？

**参考答案：** 结合任务完成率、工具调用正确率、事实准确性、安全违规率、延迟、Token 成本、人工接管率等指标。评测应包含可重复测试集、轨迹回放、失败分类与线上监控，不能只看最终回答是否流畅。

## 8. 多 Agent 一定比单 Agent 好吗？

**参考答案：** 不一定。多 Agent 适合职责清晰、可并行或需要不同权限的任务，但增加协调成本、上下文传递损耗和故障面。应先建立单 Agent 基线，再验证多 Agent 是否带来可测量的收益。

## 9. RAG 在 Agent 中有什么作用？

**参考答案：** RAG 为 Agent 提供可检索的外部知识，使回答更贴近受控资料。需要关注召回率、重排、引用来源、权限过滤、知识时效和检索结果中的提示注入风险。

## 10. 如何设计生产级 Agent 的可观测性？

**参考答案：** 为每个任务记录 trace ID、步骤、工具名、参数摘要、耗时、Token 用量、错误和结果状态；对敏感内容进行脱敏。将任务成功率与单步骤指标关联，便于定位模型、工具、检索或业务逻辑问题。
